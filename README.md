# CCC – Compact Currency Converter

Ein minimalistischer, kompakter Währungsrechner für deinen Browser, Desktop und dein Smartphone.

🌐 **Live-Web-App:** [https://andregemeinhardt.github.io/ccc/](https://andregemeinhardt.github.io/ccc/)

## Unterstützte Währungen
- **CZK** – Tschechische Krone (Kč)
- **EUR** – Euro (€)
- **USD** – US-Dollar ($)
- **VND** – Vietnamesischer Dong (₫)
- **JPY** – Japanischer Yen (¥)
- **GBP** – Britisches Pfund (£)

## Features
- **Minimalistische Dropdowns:** Beide Eingabefelder besitzen ein schlankes Dropdown-Menü, um sekundenschnell zwischen den Währungen zu wechseln.
- **Beliebige Währungspaare:** Rechne jedes Währungspaar ineinander um (z. B. CZK ⇄ EUR, USD ⇄ EUR, VND ⇄ EUR, JPY ⇄ EUR, etc.).
- **Tagesaktuelle Kurse:** Automatische Live-Kurse mit mehrstufigem Fallback und Offline-Cache.
- **Dynamische Schnellwahltasten:** Passen sich automatisch an die jeweils oben gewählte Währung an (z. B. typische Beträge für Kronen, Dong, Yen, Euro oder Dollar).
- **Intelligente Tageskurs-Anzeige:** Zeigt den aktuellen Wechselkurs immer leserlich unter den Eingabefeldern an.
- **PWA-fähig:** Kann auf Android & iPhone direkt als App auf den Startbildschirm gelegt werden.

## Installation auf dem Smartphone
- **iPhone / iPad (Safari):**
  1. Seite in Safari öffnen: [https://andregemeinhardt.github.io/ccc/](https://andregemeinhardt.github.io/ccc/)
  2. Unten auf den **Teilen-Button** tippen.
  3. **„Zum Home-Bildschirm“** auswählen und bestätigen.
- **Android (Chrome / Edge):**
  1. Seite in Chrome öffnen: [https://andregemeinhardt.github.io/ccc/](https://andregemeinhardt.github.io/ccc/)
  2. Auf die drei Punkte (Menü) tippen.
  3. **„App installieren“** oder **„Zum Startbildschirm hinzufügen“** wählen.

## Desktop / Offline
- **Windows:** Doppelklick auf `start.bat`.
- **Browser:** Doppelklick auf `index.html`.
